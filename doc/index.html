Core Concept

What is Sentinel Java Agent?

An enterprise-grade runtime instrumentation framework designed for security researchers, APM developers, and performance engineers.

Zero Disk Modifications

Operates strictly in JVM memory during classloading. Original .class or .jar files on disk remain completely unmodified and verified.

In-Memory Non-Destructive

Transformation Engines

Four Architectural Engines

Flexible ASM pipelines designed for specific observability, instrumentation, and testing tasks.

1. REPLACE Engine

Powered by ASM Tree API (ClassNode & MethodNode). Locates matching target signatures, flushes the existing instruction list, and injects constant opcodes.

LdcInsnNode InsnList Opcodes.ARETURN

2. TRACE Engine

Utilizes AdviceAdapter to hook method boundaries. Records start time via System.nanoTime() at entry, logs elapsed milliseconds, and duplicates reference returns for inspection.

onMethodEnter onMethodExit DUP return

3. COUNT Engine

High-performance concurrency tracking. Injects static hooks calling AgentStats.recordInvocation() at method headers, providing instantaneous call counts across threads.

AtomicLong Thread-Safe Telemetry

4. NULL_CHECK Engine

Defensive bytecode auditing. Injects DUP and IFNONNULL checks before ARETURN instructions to immediately log stderr warnings whenever a method yields null.

IFNONNULL Defensive Guard NPE Prevention
Under The Hood

The Bytecode Transformation Pipeline

Click any stage in the pipeline to reveal internal ASM mechanics and execution guarantees.

01

JVM Boot & Premain Registration

The JVM starts with -javaagent:sentinel-agent.jar. Loader.premain() parses configuration arguments or .properties files and registers with Instrumentation.addTransformer(loader, true).

instrumentation.addTransformer(new Loader(config), true);
02

Classloading Interception & Wildcard Gating

Every class byte stream is passed through Loader.transform(). PatternMatcher tests the internal name using glob wildcards (demo/target/* or com/example/**). Unmatched classes immediately return null.

if (!config.matches(className)) return null; // zero overhead pass-through
03

ASM Tree / Visitor Mutation

Bytecode is parsed using ClassReader(SKIP_FRAMES). Depending on the configured mode, instructions are injected into targeted methods while preserving all other members intact.

ClassWriter writer = new ClassWriter(ClassWriter.COMPUTE_FRAMES);
04

Automatic Stack-Map Frame Recomputation

Java 17 requires strict StackMapTable attributes. ClassWriter.COMPUTE_FRAMES computes stack map frames and local variable tables automatically, guaranteeing valid bytecode verification.

return writer.toByteArray(); // Bytecode verified by JVM verifier
